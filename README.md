# CareerConnect Platform

A comprehensive recruitment platform built on the **MERN stack** (MongoDB, Express, React, Node.js). This system utilizes **Python scripts** for intelligent job scraping and resume parsing to bridge the gap between candidates and opportunities.

## 🚀 Features

* **Intelligent Job Aggregation:** Automated Python scripts (Selenium) to scrape and aggregate job listings from various sources.
* **Smart Resume Parsing:** Python-based parsing engine to extract skills, education, and experience from candidate resumes.
* **Robust Backend:** Scalable Node.js & Express REST API to handle user authentication, job management, and data processing.
* **Candidate-Job Matching:** Algorithms to recommend relevant opportunities based on parsed resume data.

## 🛠️ Tech Stack

* **Frontend:** React.js, Tailwind CSS (Planned)
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Automation & Scripting:** Python, Selenium, spaCy, NLTK
